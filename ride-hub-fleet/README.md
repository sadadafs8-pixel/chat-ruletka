# Ride Hub Fleet BLE

Универсальный BLE-контур для собственного парка самокатов.

## Идея

В каждый самокат устанавливается один и тот же BLE-контроллер (например ESP32) с:
- уникальным `deviceId`;
- уникальным 32-байтовым секретом;
- реле/транзисторным выходом на штатный вход электрозамка;
- BLE-сервисом Ride Hub Fleet.

Приложение iPhone сканирует только наш Service UUID, подключается к ближайшему модулю, получает одноразовый challenge и отправляет HMAC-подписанную команду `UNLOCK`. Модуль принимает команду только если подпись верная и challenge ещё не использован.

Это решение предназначено только для самокатов, которыми вы владеете или которыми вам разрешено управлять. Оно не содержит протоколов Юрент/Whoosh/Яндекс и не обходит их авторизацию.

## UUID

- Service: `8f2a0001-9c5b-4a6e-9d51-22c3dbe00001`
- Device ID: `8f2a0002-9c5b-4a6e-9d51-22c3dbe00001` (read)
- Challenge: `8f2a0003-9c5b-4a6e-9d51-22c3dbe00001` (read/notify)
- Command: `8f2a0004-9c5b-4a6e-9d51-22c3dbe00001` (write)
- State: `8f2a0005-9c5b-4a6e-9d51-22c3dbe00001` (read/notify)

## Команда

Пакет UTF-8:

`UNLOCK|<deviceId>|<challengeHex>|<unixSeconds>|<hmacHex>`

Где `hmacHex = HMAC-SHA256(secret, "UNLOCK|deviceId|challengeHex|unixSeconds")`.

Модуль отклоняет пакет, если:
- deviceId не совпадает;
- timestamp старше 30 секунд;
- challenge не совпадает/уже использован;
- HMAC неверный.

## Файлы

- `firmware/ride_hub_fleet_esp32.ino` — прошивка ESP32.
- `ios/RideHubBluetoothManager.swift` — CoreBluetooth-клиент для iPhone.
- `ios/FleetKeyStore.swift` — пример хранилища ключей (для продакшена перенести секреты в Keychain).

## Подключение замка

ESP32 **не должен напрямую питать электрозамок**. Используйте подходящий драйвер/реле/MOSFET и отдельное питание, рассчитанное на напряжение и ток вашего замка. Управляющий GPIO только подаёт логический сигнал на драйвер.

По умолчанию в прошивке `LOCK_PIN = 26`, импульс открытия 800 мс. Измените под конкретную электронику.
